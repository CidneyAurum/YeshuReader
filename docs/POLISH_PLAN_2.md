# 页枢 · 第二轮 30 轮精细打磨计划（R51–R80）

对标对象：Moon+ Reader（朗读、自动滚动、点击区域、护眼）、Kindle（生词本、阅读目标、
本章剩余时间）、Apple Books（字体族、主题过渡）、Readwise（划线导出）。
审计方式是先按功能面 grep 现有代码，只写确实缺失的轮次。

约定与前 50 轮相同：不写入任何 API Key；默认模型用稳定别名 `deepseek-flash`；
改实体必须升 Room 版本并补 `MIGRATION_n_m`；每批次跑 `assembleDebug testDebugUnitTest`；
保留 `app/src/test/resources/corpus/` 与 kxml2 shim。

## 一、朗读与自动滚动

- **R51 朗读（TTS）**：接入系统 `TextToSpeech`，从当前位置开始按块朗读，支持暂停/继续、
  语速三档、随朗读自动高亮当前块并滚动；退出阅读器或切章时停止。
- **R52 自动滚动**：可调速的匀速滚动，供免手操作场景；触摸即暂停，松手恢复。
- **R53 朗读与自动滚动互斥**：两者同时开会互相抢滚动位置，需要显式互斥并说明原因。

## 二、排版与视觉

- **R54 字体族切换**：衬线 / 无衬线 / 等宽三选，写入 `reader_font_family`。
- **R55 护眼暖色滤镜**：可调强度的暖色叠加层，夜间阅读减少蓝光；与主题独立。
- **R56 阅读时保持常亮**：可开关，避免长章节阅读时反复息屏。
- **R57 两端对齐开关**：中文正文两端对齐更好看，但英文会出现过大字距，做成可选。
- **R58 页码显示模式**：百分比 / 剩余页 / 当前位置三选，顶栏与底栏统一口径。

## 三、阅读节奏

- **R59 本章剩余阅读时间**：按当前阅读速度估算「本章还需 N 分钟」。
- **R60 阅读目标**：每日分钟目标，进度环显示在阅读器顶栏；达成给一次轻提示。
- **R61 阅读速度统计**：统计页显示平均每分钟字数，用于校准剩余时间估算。
- **R62 长章节提示**：进入超长章节时提示预计耗时。

## 四、选词与生词

- **R63 生词本**：选中文本可「加入生词本」，独立列表，支持复习与导出。
- **R64 词典查询**：选中文本走系统 `ACTION_PROCESS_TEXT` 交给已安装词典。
- **R65 选句/选段快捷**：长按菜单增加「选整句」「选整段」。
- **R66 脚注弹注**：识别正文中的脚注引用并弹出内容，而不是跳到文末。

## 五、书架与检索

- **R67 按作者/丛书分组**：书架支持按作者、丛书聚合，组头显示条数。
- **R68 全库搜索**：一次搜索书名、作者、标签与正文，结果分组显示。
- **R69 书架排序记忆**：排序与视图偏好持久化，重进保持。
- **R70 最近阅读快速切换**：阅读器内可直接切到最近读过的其它书。

## 六、导出与统计

- **R71 导出划线为 Markdown**：把某本书的划线/笔记导出成 `.md`。
- **R72 导出全部划线**：跨书导出，按书分节。
- **R73 阅读报告增强**：统计页增加「平均速度」「最长一次阅读」等可由现有数据算出的指标。

## 七、可靠性与打磨

- **R74 数据完整性自检**：检查孤儿笔记、悬空书签、进度越界，并提供修复。
- **R75 大文件与图片性能**：超大 EPUB 的分块渲染与图片内存收口。
- **R76 备份自动执行**：按周自动导出到指定目录，失败有通知。
- **R77 无障碍完善**：补齐自绘控件与图表的描述与状态播报。
- **R78 空状态动作**：各页空状态给出下一步按钮。
- **R79 键盘与外接设备**：外接键盘支持空格翻页、方向键滚动、Esc 退出。
- **R80 收尾清理**：重复实现合并、无引用符号删除、文案一致性复查。
